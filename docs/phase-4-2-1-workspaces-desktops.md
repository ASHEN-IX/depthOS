# Phase 4.2.1 Workspaces and Logical Desktops

[WorkspacesView](../experiments/spatial-alpha/WorkspacesView.qml) carries the selected World into an illustrated context masthead. Project cards use a responsive matrix, differentiated glyphs, and a clear selected treatment. Taller layouts add a summary and an open-Desktops action for the active Workspace. Existing directory, branch, freshness, and linked-Desktop fields retain their source semantics. Demo branch and window counts remain labeled as fixture data.

[DesktopsView](../experiments/spatial-alpha/DesktopsView.qml) separates the Desktop selector cards from the window shelf. The selected card identifies the active Desktop and the shelf groups only its records. Application initials provide schematic identities. The shelf uses roles, observation timestamps, and liveness when the source provides them. Protected identities stay generic. Titles begin hidden and explicit reveal keeps the existing sanitization and redaction rules.

The command palette and Control Center now use the same [glass surface](../experiments/spatial-alpha/SpatialGlass.qml) as the Worlds summary. Search preserves local category-labeled results, hierarchy paths, and keyboard focus restoration. The Control Center retains truthful source and observer state, the three presentation controls, and geometry diagnostics.

Each dense-level body exists while interactive or fading out. Its component teardown leaves the shared selection model intact. Returning restores selection by ID. Production Controller1 currently supplies Workspace-scope policy associations. Per-Desktop window display records still require a privacy-reviewed projection.
